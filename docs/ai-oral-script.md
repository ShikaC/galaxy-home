# 侧栏 AI 口语剧本（P1b）

固定 12 条口语，用真实模型复跑；结果记入下方表格与 [dogfood-friction.md](./dogfood-friction.md)。不靠感觉。

前置：配置可用的聊天模型；准备空/干净工作区或可识别前缀（如「剧本-」）；分别在**保守**与**开放**模式下各跑一遍删除相关条目。

## 剧本

| # | 用户说法 | 期望 |
|---|----------|------|
| 1 | 帮我记一下：明天买菜 | 创建待办（或挂起确认后创建）；标题合理 |
| 2 | 建一个每天喝水的习惯，目标 8 杯 | `create_habit` 每日计数；`weeklyTarget` 为空 |
| 3 | 我想做一个两周的跑步计划 | 信息不足时追问 1–3 个问题，不硬报错建空项目 |
| 4 | 项目叫「剧本-晨跑」，目标是两周内养成晨跑，每周跑 3 次 | 创建周期项目，字段完整 |
| 5 | 把「明天买菜」排进今天 | 加入今日；若主位已满则进次要或说明 |
| 6 | 再给我加三条今日待办：A、B、C（在已有主位接近满时） | 超额主位降为次要，不整批失败 |
| 7 | 把「剧本-晨跑」进度记到 30 | 更新项目进度；不重复刷屏 |
| 8 | 删掉「明天买菜」这条待办 | **保守**：拒绝删除并提示切换开放；**开放**：挂起确认，确认后进回收站 |
| 9 | 归档「明天买菜」 | **保守**：拒绝；**开放**：立即归档 |
| 10 | 再记一条「明天买菜」 | 同名活跃待办复用或明确提示，不无谓重复堆叠 |
| 11 | 帮我建分类「剧本-生活」并把买菜归进去 | 创建分类并关联（或挂起后执行） |
| 12 | 今天完成喝水习惯 | 习惯打卡成功；休息日应诚实拒绝 |

## 失败路径检查（可与集成测试对照）

- 口头「已创建」但无操作块：不改数据，文案不谎称成功
- 坏 JSON / 字段不全：跳过坏项或整段失败说明，有效项仍可执行
- 批次中途失败：已成功步数可见；可撤销
