# Galaxy 真实模型体验与产品改进

日期：2026-09-10。模型：用户配置的 `gpt-5.6-luna`。场景：面向 AI 应用 / Agent 开发岗位准备项目证据与简历。测试在独立本地工作空间中运行，使用人工编写的模拟笔记和任务，未改动用户原预览的内容、权限或密钥。

## 使用结果

| 用户动作 | 实际观察 | 本轮改进 |
| --- | --- | --- |
| 输入只有目标的简历准备请求 | 模型要求提供项目事实；原“补充”按钮返回表单后看不到问题 | 问题旁直接填写回答，保留原目标和约束 |
| 提供技术栈、功能和测试证据 | 模型生成 3 项 / 45 分钟计划；确认入库，第一项可完成 | 长原始目标折叠展示，优先呈现具体安排 |
| 保存项目笔记并提炼重点 | 真实回复正确归纳事实，并提醒不要编造增长与性能数据 | 此流程保持现有行为 |
| 用笔记生成两天计划 | 正确引用 1 篇笔记，复用 2 项未完成任务，提出 2 项演示准备任务 | 引用可直接展开来源快照 |
| 将第一天 20/10 分钟调整为 15/15 分钟，并修改演示标题 | 旧页面只能全盘确认或取消 | 本地编辑、预算即时提示、服务端复验、版本冲突保护；保存与执行分开 |
| 确认调整后的计划 | 核验为 2 项复用、2 项新建，日期和总分钟保持正确 | 编辑不增加模型调用，旧页面不能确认新版安排 |
| 回到最初的追问补充项目资料 | 模型继续生成 12/23/10 分钟三项任务 | 202 立即打开运行状态，刷新后可继续查询 |

浏览器中完成 4 次真实规划响应，每次均一次模型响应，耗时约 9.36–13.52 秒；另外发起并取消 1 次真实规划，以及完成一次笔记提炼交互。取消后服务端晚到的响应仍保持 cancelled，结果为空，未产生任务。自动化 live 评测另运行 15 个试次，不包含固定响应回归测试。

## 小样本评测

全部使用相同模型和 `workspace-plan-v1`，每例只跑一次。

| 数据组 | 试次 | 硬性检查通过 | 需人工复核的词面提示 | p50 | p95 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 首轮作品集 | 5 | 5/5（按同一硬性口径重算） | 2 | 6.70 秒 | 11.91 秒 |
| 优化后作品集 | 5 | 5/5 | 2 | 6.98 秒 | 20.52 秒 |
| 优化后 Agent 用例 | 5 | 5/5 | 1 | 7.14 秒 | 9.73 秒 |

首轮旧报告将词面提示纳入通过率，原值是 3/5；新报告将它们分开，因此不能把表中差异解释为模型能力提升。所有试次都在第一次响应通过结构校验。硬性检查包括确认前不写任务、预期状态、引用 ID、已有任务复用、完整执行、日期/预算约束和幂等确认；不适用项为 null。

自动化三组调用共报告输入 10,456 tokens、输出 3,861 tokens；这不包含浏览器交互的 token 消耗。服务商价格未统一配置，未估算费用。小样本存在延迟波动，没有证据表明本轮降低了模型延迟。

## 工程验证边界

最终本地检查：71 个测试文件 / 239 项单元与集成测试通过（`npm test -- --maxWorkers=2`）；50 项 Playwright 全流程通过；30 个固定场景各运行 3 次，90/90 通过；类型检查、lint 和生产构建通过。规划界面另覆盖 12 个状态、375/768/1440 宽度、日间/夜间及滚动位置，共 150 张截图。并发数限制用于本机资源预算，不改变单元测试断言或超时。浏览器抽屉尺寸断言改用 0.005 像素容差，处理 380.00003 与 380 的浮点差异。

固定模型回归覆盖异步请求持久化、重复提交不重复调用、取消后不修正/写任务、草稿验证失败不污染数据、旧版本编辑与确认冲突、重复确认、刷新后恢复界面、离开未保存草稿提醒。客户端回归还模拟了另一窗口更新后后台刷新，确保旧草稿仍提交旧版本并保留本地输入。关闭流程覆盖已开始模型请求和仅收到部分 HTTP 请求体的情况。

截图中的回归测试内容来自明确的固定模型服务，不能当作真实模型成功证据。实际体验与评测数据保存在本地 `.omo/evidence/live-usage/`；凭据不在这些报告中。

## 继续验证

- 需要真实使用者持续多日体验，观察计划接受/修改/放弃比例、任务完成和重新规划频率。
- 仍需独立标注集或人工双评验证任务质量和引用是否支持具体结论。当前 ID 校验不等于语义忠实性。
- 检索仍使用字面匹配；同义表达和跨笔记综合有进一步验证空间。
- 时间预算约束针对本次计划，尚未统一计入全天已有安排和外部日历。
- 取消不保证服务商停止计费；意外重启恢复为失败，不会自动继续模型推理。
