# 决策包：本地模型（Ollama / LM Studio）

状态：**已决策 — 暂不接入 / 不正式支持本地模型**（2026-08-07）。

对照 [项目说明书.md](../项目说明书.md) §12.5、§23、§24。

## 决定

- 不开展目标机实测报告，不写「推荐本地配置」文案，不把本地模型当作产品能力宣传。
- 默认继续使用用户自行配置的**云端** AI API。
- 适配层仍允许填写本机 OpenAI 兼容地址（技术上不拆除），但**不作为功能交付、不排期、不验收**。
- 若日后要正式支持，须新开决策并完成 M1 8GB（或指定机型）质量与内存实测后再改 README / 设置文案。

## 已具备（保持现状，不扩展）

- AI 配置可指向 loopback 兼容接口（见 `aiEndpoint` 与设置页）。
- 云端不可用时，非 AI 功能仍可用。
- **不**打包大模型进安装包（§22）。
